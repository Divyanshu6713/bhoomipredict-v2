# LandPulse brand kit

Two pieces, used together:

| Asset | What it is | Use it for |
|---|---|---|
| `landpulse-logo.png` | The hand-lettered LandPulse logo, background removed (1144 × 451) | Slide headers, title and closing slides, website header, documents |
| `landpulse-logo-on-dark.png` | Same logo; the black "Pulse" and swash become off-white | Any dark or photo background |
| `landpulse-icon.svg` / `-512.png` | **Looped L** icon: the L from the logo, saffron-to-ember, on a round ink badge | Small spaces where the logo can't fit: diagram hubs, bullets, collapsed sidebar, app icon, avatar |
| `landpulse-icon-plain.svg` / `-512.png` | The looped L alone, no badge | When a round badge would clash with the background shape |
| `landpulse-favicon.svg` | Same round icon with a heavier stroke so it reads at 16–32 px | Browser tab only (copied to `public/favicon.svg`) |
| `landpulse-logo-source.png` | Original 2000 × 2000 artwork | Source only; don't place it (white background) |

**Colours:** saffron `#FF751F` (from the "L"), ember `#FF4236`, ink `#141210`, off-white `#F6F2ED`.

**Rules**
- Use the logo whenever there is room for it (at least 110 px / 1.2 in wide). Use the icon only when there isn't.
- Don't redraw, recolour, stretch or add effects to either. Leave clear space around the logo about the height of the "AND".
- Don't put the logo and the icon side by side as a lockup: the logo already contains the L the icon comes from.
- The icon is always round, never a square tile.
- In the product UI, saffron stays a brand colour. Buttons and links keep the UI blue, because orange already means "High risk" in charts and maps.
